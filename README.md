# Lumora

独立的视频浏览演示。深色玻璃导航、渐变标题和圆角片库栅格，用来搜索、筛选并播放公开短片。

这不是任何模板商店的官方站点，也没有账户或后端。片单和页脚里的邮箱只写在浏览器本地。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器在 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm run build
npm start
```

## 能做什么

- 首页片架会淡出第三行，中间是「探索」按钮；封面是从公开短片截出的静帧
- 片库筛选、分类和关键词搜索（按 `/` 打开搜索）
- 播放页：播放、暂停、进度、音量、全屏
- 把片子收入本地片单
- 桌面四列、手机两列

## 片源

动画预告来自 Blender Foundation，花朵样片来自 MDN（CC0），其余来自维基共享资源。每条播放页链向原始来源。
